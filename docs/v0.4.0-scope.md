# NiceTryGPT v0.4.0 scope

**Acceptance status:** validated by the complete research-artifact CI suite in PR #35 on 2026-09-23.

## Theme

**Reproducible Transformation Artifacts**

## Problem

v0.3.0 established preliminary external empirical evidence, but the next maturity bottleneck is not sample volume. It is whether another researcher or CTF author can inspect a transformation and reconstruct exactly what was preserved, which shortcut was tested, how human cost was bounded, which runs count as solver observations, which attempts were infrastructure failures, which values are projections, and which protocol and target belong to each study.

## Decision criterion

The v0.4 scope maximizes scientific and practical value per unit of added complexity. It deliberately excludes dashboards, hosted services, new model providers, broad adapter frameworks, and additional paid repetitions.

## Deliverables

1. Machine-readable transformation reports and JSON Schema.
2. A Human Cost Gate derived from report fields instead of self-asserted PASS.
3. An experiment manifest with exact model, protocol, targets, and collection status.
4. Explicit semantic classification of solver observations and infrastructure failures.
5. Manifest-driven evidence reports and reproducibility checks.
6. One offline command that validates the complete research artifact.
7. Updated methodology, evaluation protocol, roadmap, related work, and release metadata.

## Acceptance criteria

- Existing v0.3 raw observations are not rewritten for more favorable results.
- The v0.3.0 results.csv byte content is pinned by its Git blob hash and checked in CI.
- Raw accounting remains 50 attempts, 23 solver observations, 27 infrastructure failures.
- Interstellar observed counts remain 5+5 valid GPT runs with the same solve and shortcut counts.
- DiceMiner remains 10 valid BEFORE and 3 valid AFTER, with seven AFTER observations still missing.
- The Claude attempt remains an infrastructure failure with no valid solver observation.
- Every transformation artifact is machine-readable and passes the derived Human Cost Gate.
- Negative tests prove the gate rejects excessive required actions and new exploit primitives.
- Evidence status regenerates exactly from raw data plus the experiment manifest.
- CI and release validation execute the same complete offline verifier.
- All version, citation, plugin, website, roadmap, and release metadata agree.

## Validation added in v0.4

The release validates software and methodology contracts offline. It does not perform new LLM calls.

Validated properties include bundled BEFORE/AFTER demo behavior, transformation-report semantics, evaluation row classification, preregistered run ceilings, evidence snapshot reproducibility, harness unit tests, and skill/plugin synchronization.

## Claims allowed

- reproducibility and auditability improved in v0.4.0;
- the recorded Human Cost Gate is machine-checkable;
- the v0.3 empirical accounting is reproducible from the raw dataset;
- observed shortcut reduction may be reported for the cells actually observed;
- DiceMiner remains resource-bounded partial evidence.

## Claims not allowed

- AI-proof or universally LLM-resistant;
- beats GPT, Claude, or another model;
- cross-model replication;
- new empirical evidence from v0.4.0;
- statistically demonstrated human-difficulty preservation;
- synthetic completion of missing runs.

## Cost decision

No new paid benchmark is required for this milestone. A future paid evaluation should be justified only if it adds information not obtainable through deterministic validation, a new independently authored challenge, a meaningful model-family replication, or human-author validation.
