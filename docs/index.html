THE METHOD

Increase uncertainty, not complexity.

The goal is not to make a challenge annoying. It is to remove the cheapest shortcut that lets a model jump directly to the intended exploit path.

01

Reproduce first

Solve the original challenge end-to-end before changing anything. If the baseline cannot be reproduced, stop.

02

Change less

Apply one resistance pattern where possible: runtime discovery, context split, state dependency or a small semantic decoy.

03

Verify again

Confirm the shortcut is gone, normal behavior still works and the intended vulnerability still reaches success.

EVIDENCE DISCIPLINE

No “AI-proof” claims.

NiceTryGPT distinguishes deterministic regression testing from independent model evaluation. A same-model self-review is not treated as evidence of resistance.
