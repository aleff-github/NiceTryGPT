# NiceTryGPT v0.5.0 scope

## Theme

**Structural generalization without synthetic evidence.**

v0.5.0 broadens the deterministic artifact set instead of spending model tokens to mechanically enlarge the existing benchmark cells.

## Research question

Can the same minimal-diff preservation contract be encoded and deterministically verified across a broader set of vulnerability classes and resistance patterns?

This is a structural reproducibility question, not a population-level estimate of model performance.

## Deliverables

- five bundled deterministic demos in total;
- command injection and server-side template injection as new bundled classes;
- primary examples of pattern break and state dependency;
- all five resistance patterns represented somewhere in the committed transformation set;
- one executable adapter per bundled demo;
- generated generalization status from transformation reports plus adapter coverage;
- CI enforcement of the adapter and generalization contracts.

## Evidence boundary

v0.5.0 does not add paid model observations. Interstellar Ingress and DiceMiner remain the only transformations with valid fresh-solver observations in the committed evidence set.

The new bundled demos are deterministic artifacts. Their Human Cost Gate is a structural bound, not a human-subject measurement. Pattern coverage is not evidence that every pattern is effective on every challenge.

## Explicit non-goals

- completing the seven missing DiceMiner AFTER observations by imputation or forced spending;
- claiming cross-model replication;
- claiming universal LLM resistance;
- recruiting human participants as a release dependency;
- turning NiceTryGPT into a hosted framework, dashboard, or challenge generator.
