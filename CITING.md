# Citing NiceTryGPT

NiceTryGPT provides machine-readable citation metadata in [CITATION.cff](CITATION.cff). GitHub reads that file and exposes a **Cite this repository** control with generated APA and BibTeX formats.

For work that depends on a specific NiceTryGPT release, cite the release version you actually used rather than the moving main branch.

The canonical citation for the current release is:

> Greco, A. (2026). *NiceTryGPT* (Version 0.5.0) [Computer software]. GitHub. https://github.com/aleff-github/NiceTryGPT/releases/tag/v0.5.0

A version-specific Zenodo DOI for v0.5.0 should be substituted once the release deposit is minted. Until then, do not reuse the v0.2.0 DOI as if it identified v0.5.0.

The archived Zenodo record for v0.2.0 remains available at https://zenodo.org/records/22858477 with DOI https://doi.org/10.5281/zenodo.22858477.

A DOI identifies a specific archived software release; it does not imply peer review of the software or its methodology.

## Research use

When reporting experiments based on NiceTryGPT, record the NiceTryGPT release or commit, challenge and before/after variant, exact model version, tool access and execution limits, fresh-context run count, and evaluation protocol version.

The reproducible evaluation schema is documented in [evals/protocol.md](evals/protocol.md).
